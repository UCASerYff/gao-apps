01能做什么What it does

摘自From the GaoWenJian README

  • LaTeX

    识别主文件与 % !TeX root，大纲导航与智能补全；结构化诊断；SyncTeX 双向定位；内置 Tectonic 离线编译，也支持本机 XeLaTeX / pdfLaTeX / LuaLaTeX。Detects the main file and % !TeX root, with outline navigation and smart completion; structured diagnostics; two-way SyncTeX. Offline compile with the included Tectonic, and also with XeLaTeX, pdfLaTeX, or LuaLaTeX already on the Mac.

  • Markdown

    即时块编辑、源码与分屏、大纲、表格、公式、Mermaid、代码高亮，可导出 HTML / PDF。Live block editing, source and split view, an outline, tables, math, Mermaid, and code highlighting, with export to HTML or PDF.

  • PDF 编辑PDF editing

    阅读、搜索、批注、表单，插入文字与图片；页面旋转、裁剪、排序、合并、拆分；提供 OCR 交接入口。Read, search, annotate, and fill forms; insert text and images; rotate, crop, reorder, merge, and split pages. Includes an entry that hands off to OCR.

  • Office 与表格Office and tables

    Word / Excel / PPT 只读预览；CSV / TSV 可在源码与表格间切换，筛选、排序、增行列。Read-only preview for Word, Excel, and PowerPoint. CSV and TSV can switch between source and a table, with filter, sort, and adding rows or columns.

  • 桌面便笺Desktop notes

    富文本与图片 / PDF 附件、六色分组、搜索和回收站；独立桌面窗口，可置顶、半透明。Rich text with image and PDF attachments, six color groups, search, and a trash. A separate desktop window that can stay on top and turn translucent.

02V1.11 更新What's new in V1.11

摘自正式发布说明From the stable release notes

  • 重新设计工作台：暖白与深石墨配色，森林绿强调，LaTeX 与 Markdown 入口优先。The workbench is redesigned: warm white and deep graphite, a forest-green accent, with the LaTeX and Markdown entries first.
  • PDF 编辑与 OCR 同组，Office 查看合并为一个入口，最近文件可直接继续。PDF editing and OCR are in the same group, Office viewing is a single entry, and recent files can be continued directly.
  • 移除保存前历史快照、工作区 ZIP 备份等自动备份；外部修改冲突仍阻止覆盖。Automatic backups such as pre-save history snapshots and workspace ZIP backups are removed. A conflict with an external edit still blocks overwriting.

最新版本已更新为 V1.11，更新内容请看 发布说明。The latest version is now V1.11. See the Release notes for what changed.

03安装与校验Install and verify

如实说明，不做夸大As stated, without embellishment

系统要求Requirements

  • macOS 14 或更高版本macOS 14 or later
  • Apple Silicon（M 系列芯片）Apple Silicon (M-series)
  • 暂未提供 Intel 版本No Intel version is offered

安装Install

打开 DMG，把「搞文件」拖入「应用程序」。默认安装位置 /Applications/搞文件.app。Open the DMG and drag 搞文件 into Applications. The default location is /Applications/搞文件.app.

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。If macOS blocks the app, confirm the download source, then allow it in System Settings → Privacy & Security.

签名与数据Signing and data

未经 Apple 公证。README 写作「本地签名」，V1.11 发布说明写作固定 Apple Development 身份逐组件签名。Not notarized by Apple. The README calls it 本地签名 (locally signed). The V1.11 release notes say each component is signed with a fixed Apple Development identity. 未上架 App Store。Not listed on the App Store.
