能做什么

摘自 GaoWenJian README

  • LaTeX

    识别主文件与 % !TeX root，大纲导航与智能补全；结构化诊断；SyncTeX 双向定位；内置 Tectonic 离线编译，也支持本机 XeLaTeX / pdfLaTeX / LuaLaTeX。

  • Markdown

    即时块编辑、源码与分屏、大纲、表格、公式、Mermaid、代码高亮，可导出 HTML / PDF。

  • PDF 编辑

    阅读、搜索、批注、表单，插入文字与图片；页面旋转、裁剪、排序、合并、拆分；提供 OCR 交接入口。

  • Office 与表格

    Word / Excel / PPT 只读预览；CSV / TSV 可在源码与表格间切换，筛选、排序、增行列。

  • 桌面便笺

    富文本与图片 / PDF 附件、六色分组、搜索和回收站；独立桌面窗口，可置顶、半透明。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

打开 DMG，把「搞文件」拖入「应用程序」。默认安装位置 /Applications/搞文件.app。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

未经 Apple 公证。README 写作「本地签名」，V1.11 发布说明写作固定 Apple Development 身份逐组件签名。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/GaoWenJian
