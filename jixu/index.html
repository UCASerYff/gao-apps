能做什么

摘自 GaoJiXu README

  • 四个工作区

    总览、收支、攒钱、冒险。流水与积蓄记录按日期分组展示。

  • 日常账本

    日常记账、资产账户、余额调整、转账、预算、收支报表和周期记账。

  • 固定收支

    固定收入只生成预测，实际到账后再确认入账；固定支出与权益管理订阅、支付历史和提醒。

  • 攒钱目标

    攒钱目标与积蓄记录；已确认的固定支出可记为支出，同一支付单号不会重复入账。

  • 勇者冒险

    装备、技能、宠物、祈愿和成就；游戏资源与真实财务记录分开保存。

  • 小组件

    从菜单或 ⌘, 打开设置；提供桌面与通知中心小组件。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

解压 ZIP，把「搞积蓄.app」拖入「应用程序」文件夹。安装后运行一次，再从系统小组件列表添加小组件。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

Apple Development 签名，未经 Apple 公证。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/Savings/
