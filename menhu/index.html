能做什么

摘自 GaoMenHu README

  • 网站启动台

    Launchpad 风格排列，拖动排序、组合文件夹；双指横向翻页，可导入 Chrome / Edge 收藏栏。

  • 指定浏览器

    每个网站可指定 Chrome、Edge、Safari 或 Firefox；Chrome、Edge 装上「搞门户助手」后支持账号自动填充。

  • 贴边悬浮窗

    左右贴边收起为细条，悬停展开，优先显示最近和常用网站；支持名称、网址、拼音和简称搜索。

  • 工作场景

    一次打开多个网站，各自使用指定的浏览器和账号。

  • 下载中心与原生邮件

    在应用内复核网址和保存目录再管理下载队列；原生邮件支持收件箱、草稿及附件，明确连接后才收发。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

打开 DMG，把「搞门户.app」拖入「应用程序」后启动。需要自动填充时，在 Chrome 或 Edge 的扩展页以开发者模式加载应用内的 BrowserExtension。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

Apple Development 签名，未经 Apple 公证。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/MenDao/
