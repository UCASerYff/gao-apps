能做什么

摘自 GaoYanJiu README

  • 论文与成果

    管理论文、成果、证书和投稿状态；状态更新、已归档是在投管理里的页签。科研资金已改由搞积蓄管理。

    建筑、扩建与研究进度联动，科研推进会体现在城市上。

    从菜单或 ⌘, 打开设置，含外观、模块设置和本地数据目录入口；提供桌面与通知中心小组件。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

解压 ZIP，把「搞研究.app」拖入「应用程序」文件夹。安装后运行一次，再从系统小组件列表添加小组件。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

Apple Development 签名，未经 Apple 公证。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/Research/
