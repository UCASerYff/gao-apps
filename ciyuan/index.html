搞词元

GaoCiYuan

Agent 软件的额度和词元消耗，一页看清。

独立 macOS Agent 软件额度与用量管理应用，包含紧凑总览、Agent 软件管理、用量分析、平台接入和悬浮窗。第三方数据读取需要对应软件及本机已有的登录状态。

能做什么

摘自 GaoCiYuan README

  • 四页紧凑导航

    总览、Agent 软件、用量分析、平台接入；支持动态深浅色和浮动面板。

  • 只管 Agent 软件

    管理 Agent 软件的真实额度、账单连接和本地用量，不再新增大模型 API 或自定义 API 余额账户。

  • 用量分析

    按工具、模型、时间等维度查看词元消耗，核对重复日志和跨来源记录。

  • Tokscale 扫描引擎

    内置 Tokscale 扫描引擎及本地修订，版本与源码补丁随仓库公开。

  • 导出

    设置里提供外观、数据来源和 CSV／用量 JSON 导出。桌面与通知中心小组件已不再提供。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

解压 ZIP，把「搞词元.app」拖入「应用程序」文件夹。注意：V4.13 起旧 LLM 与自定义 API 账户会在启动时永久删除。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

Apple Development 签名，未经 Apple 公证。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/Token/
