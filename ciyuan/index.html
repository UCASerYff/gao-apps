搞词元

GaoCiYuan

Agent 软件的额度和词元消耗，一页看清。Quotas and token use for Agent apps, clear on one page.

独立 macOS Agent 软件额度与用量管理应用，包含紧凑总览、Agent 软件管理、用量分析、平台接入和悬浮窗。第三方数据读取需要对应软件及本机已有的登录状态。A standalone macOS app for Agent-app quotas and usage, with a compact overview, Agent-app management, usage analysis, platform connections, and a floating panel. Reading third-party data requires that software and an existing login on this Mac.

01能做什么What it does

摘自From the GaoCiYuan README

  • 四页紧凑导航Four compact pages

    总览、Agent 软件、用量分析、平台接入；支持动态深浅色和浮动面板。Overview, Agent apps, Usage analysis, and Platform connections. Supports dynamic light and dark appearance, and a floating panel.

  • 只管 Agent 软件Agent apps only

    管理 Agent 软件的真实额度、账单连接和本地用量，不再新增大模型 API 或自定义 API 余额账户。Manage real quotas, billing connections, and local usage for Agent apps. New large-model API or custom API balance accounts are no longer added.

  • 用量分析Usage analysis

    按工具、模型、时间等维度查看词元消耗，核对重复日志和跨来源记录。View token use by tool, model, time, and other dimensions, and check duplicate logs and records from more than one source.

  • Tokscale 扫描引擎Tokscale scan engine

    内置 Tokscale 扫描引擎及本地修订，版本与源码补丁随仓库公开。Includes the Tokscale scan engine and local revisions. The version and source patches are public in the repository.

  • 导出Export

    设置里提供外观、数据来源和 CSV／用量 JSON 导出。桌面与通知中心小组件已不再提供。Settings offer appearance, data sources, and export to CSV or usage JSON. Desktop and Notification Center widgets are no longer provided.

02V4.13 更新What's new in V4.13

摘自正式发布说明From the stable release notes

  • 全新紧凑四页界面：总览、Agent 软件、用量分析、平台接入。A new compact four-page interface: Overview, Agent apps, Usage analysis, and Platform connections.
  • 平台体系统一为真实 Agent 软件，启动时清理旧 LLM／自定义 API 数据及专属凭据。The platform model is now real Agent apps only. On launch, old LLM and custom API data, and their credentials, are cleared.
  • 删除完整资料备份、每日自动备份和恢复入口；现有 Agent 账户、历史用量和设置保留。Full-data backups, daily automatic backups, and the restore entry are removed. Existing Agent accounts, usage history, and settings are kept.

最新版本已更新为 V4.13，更新内容请看 发布说明。The latest version is now V4.13. See the Release notes for what changed.

03安装与校验Install and verify

如实说明，不做夸大As stated, without embellishment

系统要求Requirements

  • macOS 14 或更高版本macOS 14 or later
  • Apple Silicon（M 系列芯片）Apple Silicon (M-series)
  • 暂未提供 Intel 版本No Intel version is offered

安装Install

解压 ZIP，把「搞词元.app」拖入「应用程序」文件夹。注意：V4.13 起旧 LLM 与自定义 API 账户会在启动时永久删除。Unzip and drag 搞词元.app into the Applications folder. Note: from V4.13, old LLM and custom API accounts are permanently deleted on launch.

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。If macOS blocks the app, confirm the download source, then allow it in System Settings → Privacy & Security.
