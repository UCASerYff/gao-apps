专注、睡眠与习惯，按一天的节奏排好。

能做什么

摘自 GaoJieZou README

  • 五个工作台

    今天、节奏、健康、足迹、乐园；旧通知与深链仍打开原业务。

  • 专注与作息

    专注计时、手动睡眠、习惯、琐事、目标和统计，用统一的轻卡片窗口记录。

  • 健康记录

    今日、全部记录、统计趋势和快速事项；全部记录可按类型、时间筛选和搜索。

  • 后台专注

    关闭窗口后专注在后台继续，点 Dock 图标或按 ⌘0 重新打开；⌘Q 保存并暂停后退出。

  • 乐园

    农场、牧场、钓鱼、图鉴、荒岛与旅行列车集中在乐园里。

  • 小组件

    提供本应用的桌面与通知中心小组件。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

解压 ZIP，把「搞节奏.app」拖入「应用程序」文件夹。安装后运行一次，再从系统小组件列表添加小组件。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

Apple Development 签名，未经 Apple 公证。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/Rhythm/
