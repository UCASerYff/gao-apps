搞操作

GaoCaoZuo

文件、窗口、剪贴板和截图，收进一个操作库。

原生 macOS 操作增强工具，把文件处理、窗口控制、剪贴板、压缩包与自定义动作集中到一个操作库，通过主窗口、菜单栏、快捷面板、访达菜单、系统服务和输入规则调用。

能做什么

摘自 GaoCaoZuo README

  • 操作面板

    搜索动作、收藏常用动作；默认 ⌥⌘O 呼出，也可以从访达右键菜单、系统服务和菜单栏调用。

  • 文件工具

    新建文本、Markdown 与文件夹，复制路径和 SHA-256，批量重命名预览，图片转换和缩放，二维码。

  • 压缩工具

    创建 ZIP / 7Z，支持加密、分卷和 7Z 固实压缩；可查看包内列表并选择提取，不静默覆盖重名项目。

  • 窗口控制

    左右 / 上下半屏、四角、三分屏、居中、移到其他显示器；可选拖动到屏幕边缘吸附。

  • 剪贴板与输入规则

    剪贴板堆栈与短语（采集默认关闭）；自定义快捷键、鼠标按钮和 Option＋右键方向手势；组合操作按顺序执行。

  • 截图与录屏

    V1.15 起整合截图、长截图、标注、OCR、贴图、录屏录音、GIF 及本机翻译。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

打开 DMG，把「搞操作」放入「应用程序」。窗口与输入相关功能需要在系统设置中授予辅助功能等权限。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

固定 Apple Development 签名，未使用 Developer ID，未经 Apple 公证。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/GaoCaoZuo
