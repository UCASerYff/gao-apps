搞操作

GaoCaoZuo

文件、窗口、剪贴板和截图，收进一个操作库。Files, windows, the clipboard, and screenshots, gathered into one action library.

原生 macOS 操作增强工具，把文件处理、窗口控制、剪贴板、压缩包与自定义动作集中到一个操作库，通过主窗口、菜单栏、快捷面板、访达菜单、系统服务和输入规则调用。A native macOS tool for extra actions. File handling, window controls, the clipboard, archives, and custom actions sit in one action library, and can be called from the main window, the menu bar, a quick palette, the Finder menu, system Services, and input rules.

01能做什么What it does

摘自From the GaoCaoZuo README

  • 操作面板Action palette

    搜索动作、收藏常用动作；默认 ⌥⌘O 呼出，也可以从访达右键菜单、系统服务和菜单栏调用。Search actions and favorite the ones you use. The default shortcut is ⌥⌘O. It can also be called from the Finder context menu, system Services, and the menu bar.

  • 文件工具File tools

    新建文本、Markdown 与文件夹，复制路径和 SHA-256，批量重命名预览，图片转换和缩放，二维码。New text files, Markdown, and folders; copy a path and a SHA-256; preview a batch rename; convert and scale images; QR codes.

  • 压缩工具Archive tools

    创建 ZIP / 7Z，支持加密、分卷和 7Z 固实压缩；可查看包内列表并选择提取，不静默覆盖重名项目。Create ZIP and 7Z, with encryption, splitting, and 7Z solid compression. You can view the list inside an archive and choose what to extract. Items with the same name are not overwritten silently.

  • 窗口控制Window controls

    左右 / 上下半屏、四角、三分屏、居中、移到其他显示器；可选拖动到屏幕边缘吸附。Left and right halves, top and bottom halves, four corners, thirds, center, and move to another display. Optional snapping when a window is dragged to a screen edge.

  • 剪贴板与输入规则Clipboard and input rules

    剪贴板堆栈与短语（采集默认关闭）；自定义快捷键、鼠标按钮和 Option＋右键方向手势；组合操作按顺序执行。A clipboard stack and phrases (capture is off by default). Custom shortcuts, mouse buttons, and Option + right-click direction gestures. Combined actions run in order.

  • 截图与录屏Screenshots and recording

    V1.15 起整合截图、长截图、标注、OCR、贴图、录屏录音、GIF 及本机翻译。From V1.15: screenshots, scrolling capture, annotation, OCR, pinned images, screen and audio recording, GIF, and translation on this Mac.

  • 重做初始工作台：青绿配色、系统深浅色、四个主要入口、个人收藏与文件快处理。The opening workbench is redone: a teal palette, system light and dark appearance, four main entries, personal favorites, and quick file actions.

03安装与校验Install and verify

如实说明，不做夸大As stated, without embellishment

系统要求Requirements

  • macOS 14 或更高版本macOS 14 or later
  • Apple Silicon（M 系列芯片）Apple Silicon (M-series)
  • 暂未提供 Intel 版本No Intel version is offered

安装Install

打开 DMG，把「搞操作」放入「应用程序」。窗口与输入相关功能需要在系统设置中授予辅助功能等权限。Open the DMG and put 搞操作 into Applications. Window and input features need Accessibility and related permissions in System Settings.

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。If macOS blocks the app, confirm the download source, then allow it in System Settings → Privacy & Security.

签名与数据Signing and data

固定 Apple Development 签名，未使用 Developer ID，未经 Apple 公证。Signed with a fixed Apple Development identity. Developer ID is not used. Not notarized by Apple. 未上架 App Store。Not listed on the App Store.
