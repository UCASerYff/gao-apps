下载说明

每个应用独立发版

始终最新

下载按钮指向各应用仓库最新正式 Release 中的安装包。本站每小时自动核对一次，页面打开时也会再向 GitHub 查询。

签名情况

安装包使用 Apple Development 签名（搞文件见其页面说明），均未经 Apple 公证，也未上架 App Store。首次打开可能需要在「隐私与安全性」中允许。

校验

每个安装包旁都附有同名 .sha256 文件，下载后可用 shasum -a 256 -c 核验。
