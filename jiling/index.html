搞机灵

GaoJiLing

电脑的小动静，一眼就知道。

原生 macOS 边缘系统监控工具，使用 SwiftUI、AppKit、Mach/IOKit/libproc 和 SQLite。监控记录保存在本机，无第三方运行时，无 AI，无账号。

能做什么

摘自 GaoJiLing README

  • 边缘悬浮面板

    收起时只是屏幕边上的一条竖线，悬停或点击展开；默认 ⌥⌘G 呼出。

  • 实时监控

    CPU、内存压力、压缩内存、Swap、网络与磁盘吞吐、应用排行，以及按机型可读的传感器。

  • 回看与任务

    最近 24 小时趋势回看；手动记录编译、渲染等任务的时长、平均与峰值并导出。

  • 清理与存储分析

    限定范围的旧缓存、日志与 Xcode 构建产物，确认后移入废纸篓并可按批恢复；存储分析和磁盘地图只读不删。

  • 卷与镜像

    V1.15 起提供本机内置卷信息和普通 NTFS 卷镜像的只读分析。

  • 应用管理与内存回收

    逐项确认后卸载应用并可恢复；展示真实内存读数和回收结果，不承诺提速。

安装与校验

如实说明，不做夸大

系统要求

  • macOS 14 或更高版本
  • Apple Silicon（M 系列芯片）
  • 暂未提供 Intel 版本

安装

打开 DMG，把「搞机灵.app」拖入「应用程序」。更新时先退出旧版再替换；历史、任务和设置保存在独立的数据目录中。

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。

签名与数据

Apple Development 签名，未作 Developer ID 签名或公证。由旧 ad-hoc 签名切换而来，系统权限需重新授权。未上架 App Store。

安装包不含任何个人数据。本地数据目录：~/Library/Application Support/GaoSeries/GaoJiLing/
