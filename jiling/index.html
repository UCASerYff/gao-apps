01能做什么What it does

摘自From the GaoJiLing README

  • 边缘悬浮面板Edge panel

    收起时只是屏幕边上的一条竖线，悬停或点击展开；默认 ⌥⌘G 呼出。When collapsed it is only a vertical line at the screen edge. Hover or click to expand. The default shortcut is ⌥⌘G.

  • 实时监控Live monitoring

    CPU、内存压力、压缩内存、Swap、网络与磁盘吞吐、应用排行，以及按机型可读的传感器。CPU, memory pressure, compressed memory, swap, network and disk throughput, per-app rankings, and sensors that are readable on the current Mac model.

  • 回看与任务History and tasks

    最近 24 小时趋势回看；手动记录编译、渲染等任务的时长、平均与峰值并导出。Review trends for the last 24 hours. Manually record the duration, average, and peak of tasks such as compiles and renders, and export them.

  • 清理与存储分析Cleanup and storage analysis

    限定范围的旧缓存、日志与 Xcode 构建产物，确认后移入废纸篓并可按批恢复；存储分析和磁盘地图只读不删。A limited set of old caches, logs, and Xcode compilation products can be moved to the Trash after confirmation, and restored by batch. Storage analysis and the disk map are read-only and do not delete.

  • 卷与镜像Volumes and images

    V1.15 起提供本机内置卷信息和普通 NTFS 卷镜像的只读分析。From V1.15, read-only analysis of this Mac’s built-in volume information and of ordinary NTFS volume images.

  • 应用管理与内存回收App management and memory reclaim

    逐项确认后卸载应用并可恢复；展示真实内存读数和回收结果，不承诺提速。Uninstall an app after confirming it, and restore it. Shows real memory readings and reclaim results, and does not promise a speedup.

02V1.16 更新What's new in V1.16

摘自正式发布说明From the stable release notes

  • 移除升级安装时的资料备份、旧程序回滚归档和恢复前的自动安全备份。Removes data backups taken during an upgrade install, rollback archives of the previous app, and the automatic safety backup before a restore.
  • 用户主动导出、从所选文件恢复仍保留。Exporting yourself, and restoring from a file you choose, are still available.
  • 签名从旧的 ad-hoc 身份改为 Apple Development，系统权限不会自动继承，需要时请在系统设置中重新授权。Signing changed from the old ad-hoc identity to Apple Development. System permissions are not carried over automatically; grant them again in System Settings when needed.

最新版本已更新为 V1.16，更新内容请看 发布说明。The latest version is now V1.16. See the Release notes for what changed.

03安装与校验Install and verify

如实说明，不做夸大As stated, without embellishment

系统要求Requirements

  • macOS 14 或更高版本macOS 14 or later
  • Apple Silicon（M 系列芯片）Apple Silicon (M-series)
  • 暂未提供 Intel 版本No Intel version is offered

安装Install

打开 DMG，把「搞机灵.app」拖入「应用程序」。更新时先退出旧版再替换；历史、任务和设置保存在独立的数据目录中。Open the DMG and drag 搞机灵.app into Applications. When updating, quit the old version before replacing it. History, tasks, and settings stay in a separate data directory.

如果 macOS 拦截打开，先确认下载来源，再到「系统设置 → 隐私与安全性」允许打开。If macOS blocks the app, confirm the download source, then allow it in System Settings → Privacy & Security.

签名与数据Signing and data

Apple Development 签名，未作 Developer ID 签名或公证。由旧 ad-hoc 签名切换而来，系统权限需重新授权。Signed with Apple Development. Not Developer ID signed or notarized. Switched over from the old ad-hoc signature, so system permissions need to be granted again. 未上架 App Store。Not listed on the App Store.

安装包不含任何个人数据。本地数据目录：The installer contains no personal data. Local data directory:

~/Library/Application Support/GaoSeries/GaoJiLing/
